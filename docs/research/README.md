# Research tools for Office teams

This optional toolset helps a team record current research before a technology-dependent design decision. It includes a discovery catalog, an offline evidence checker and a research skill installer. It does not run automatically when Office starts.

- [Research protocol](RESEARCH_PROTOCOL.md): project scope, source freshness, comparisons and reviewer responsibilities.
- [Catalog guide](catalog-guide.md): refresh a public discovery list, retain source provenance and compare additions/removals.
- [Model evaluation worksheet](local-model-research.md): collect artifact identity and workload evidence without prescribing a particular model or workstation.
- [Production readiness](production-readiness.md): define measurable release checks separately from the research decision.
- [Research skill](co-pre-design-research/SKILL.md): portable instructions for whichever lead owns the task.
- [Installer guide](installer.md): preview profile/skill changes and optionally apply them to a chosen local office.
- [Verification](VERIFICATION.md): offline tests, scope and limits.

The catalog is discovery data. It does not verify each listed project's license, release, security or suitability. Research packets remain private in the chosen workspace; do not commit client material, credentials or installation receipts.

No staff names, fixed roster size, GPU, model exclusion or organization-specific approval workflow is required. Each office supplies its own environment policy, accountable reviewer and project requirements. Research records do not grant permission to install models, change services or perform production work.
